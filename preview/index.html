    How a sentence becomes a file

    The detector names a scene: portrait, animal, architecture, or general. Your sentence is added to that scene name. A blank sentence becomes “faithful neutral correction” plus the scene.

    Each recipe is a JSON file. Its title, scene tags, vibe words, and description become a term-frequency vector. The folder it sits in is not part of that vector. Cosine similarity finds the nearest vector. A small bonus is added when the recipe lists the detected scene.

    That is the whole retrieval step. There is no separate database and no model reading filenames. A sentence embedding can replace the word counts later; the rest of the pipeline would stay the same.

    Use this inside Darktable

    Install the Python requirements, symlink this project to <darktable config>/lua/ai_editor, and add require "ai_editor/ai_editor" to luarc. Restart Darktable, select a photo on the lighttable, and press Run AI Analysis. The same vibe string is a Lua preference named “AI editor: vibe”.
